================================================================================
🌱 AGRO-AI PROJECT - ONE-CLICK INSTALLATION & RUN GUIDE (JUPYTER & STREAMLIT) 🌱
================================================================================

This file contains everything you need to install Jupyter Notebook, Streamlit, 
Machine Learning libraries (Scikit-Learn, Random Forest, etc.), and run the project.

--------------------------------------------------------------------------------
OPTION 1: RUN IN COMMAND PROMPT / TERMINAL (FASTEST)
--------------------------------------------------------------------------------
1. Open Command Prompt (cmd) or PowerShell.
2. Copy and paste the following single line and press ENTER:

python -m pip install --upgrade pip && pip install notebook jupyterlab streamlit pandas numpy scikit-learn plotly seaborn matplotlib ipywidgets requests

3. Once installation completes:
   - To launch Jupyter Notebook, run:
     jupyter notebook

   - To launch your AgroAI Streamlit App, run:
     streamlit run "d:\ml project\main.py"


--------------------------------------------------------------------------------
OPTION 2: RUN DIRECTLY INSIDE A JUPYTER NOTEBOOK CELL
--------------------------------------------------------------------------------
If you already opened Jupyter Notebook and want to install all required packages 
inside a notebook cell, copy and run this code inside the first cell:

!pip install --upgrade pip
!pip install notebook jupyterlab streamlit pandas numpy scikit-learn plotly seaborn matplotlib ipywidgets requests

# To launch the Streamlit App directly from Jupyter:
!streamlit run "d:/ml project/main.py"


--------------------------------------------------------------------------------
OPTION 3: AUTOMATIC WINDOWS 1-CLICK SCRIPT (.BAT)
--------------------------------------------------------------------------------
You can save the following code as "run_setup.bat" and just double-click it:

@echo off
title Installing AgroAI ML & Jupyter Dependencies...
echo ===================================================
echo   Installing Jupyter, Streamlit & ML Algorithms...
echo ===================================================
python -m pip install --upgrade pip
pip install notebook jupyterlab streamlit pandas numpy scikit-learn plotly seaborn matplotlib ipywidgets requests
echo.
echo ===================================================
echo   Installation Complete! Launching Application...
echo ===================================================
start cmd /k "streamlit run main.py"
start cmd /k "jupyter notebook"
pause

================================================================================
LIST OF INSTALLED PACKAGES & WHAT THEY DO:
================================================================================
1. notebook / jupyterlab  : Web-based interactive computing environment (Jupyter)
2. streamlit              : Modern Python Web GUI Framework
3. scikit-learn           : Machine Learning Algorithms (Random Forest, Gradient Boosting, etc.)
4. pandas                 : Data analysis & manipulation
5. numpy                  : Fast numerical computations & arrays
6. plotly                 : Interactive charts (Bar charts, Line graphs, Pie charts)
7. seaborn / matplotlib   : Statistical data visualization
8. ipywidgets             : Interactive widgets inside Jupyter notebooks
================================================================================
